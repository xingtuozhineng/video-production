# 风格预设与参考证据

## 将一句定调转换成参数

用户不必填写参数表。Agent 根据定调生成以下结构；数值均为起点，随真人构图与实帧调整。

```json
{
  "name": "克制商业知识口播",
  "tone": "清晰、可信、有重点",
  "pacing": "紧凑但保留逻辑落点",
  "pause_targets_ms": {"within_sentence": 20, "expansion": 30, "sentence": 60, "topic": 120},
  "preserve_unique_content": true,
  "caption": {
    "body": "细白字",
    "emphasis": "粗白字，少量主题色",
    "max_lines": 2,
    "position": "胸前，避开脸嘴和重要手势",
    "highlight_policy": "对比项、数字、核心名词或结论，按语义选择"
  },
  "persistent_title": "短两行，素材有足够顶部空间时使用",
  "accent": "由用户风格或参考片选择并实帧校准",
  "motion": "低强度，重点随重音进入",
  "bgm": "无指定素材时保留纯人声",
  "output": {"width": "按原片显示长短边计算的竖屏宽度", "height": "按原片显示长短边计算的竖屏高度", "fps": "探测后的源帧率 num/den"}
}
```

`output` 中的文字仅是结构示意，实际 `style.json` 按 [固定口播流水线](../../video-production/references/stable-talking-head.md) 写入竖屏规格，保留源片分辨率等级与帧率；视觉风格参考不决定输出规格。重新取景需检查人物和手势，不能直接居中裁切一切素材。

## 历史参考片的两个预设候选

证据来自 2026-09-15 对维护者本机参考片（未公开）进行的 OpenCV 元数据和每条八张抽帧。它们是视觉预设候选，未完整听审、未反向重建工程。

| 预设 | 参考成片 | 已观察 | 适合的定调 |
|---|---|---|---|
| 克制商业 | 飞书20260914-173528.mp4，136.30 秒 | 顶部两行标题；蓝绿色用于标题部分词；胸前细白正文与粗白重点；部分重点下划线；样本内以真人为主 | 商业认知、专业解释、简洁可信 |
| 强观点商业 | 飞书20260914-173536.mp4，307.24 秒 | 顶部两行标题；铜棕强调色与粗白重句；局部大字 | 对比、观点、方案讲解，适度强调 |

精确字体、源色值、动画速度、音乐未测定。不要把抽帧中的人物远近变化全部归因于后期推拉。调色只可描述成片外观，尚不能从采样证明用了何种滤镜或磨皮。

后续独立任务的连续内容/抽帧对照补充了先前稀疏抽样没有覆盖的部分：蓝绿主要用于顶部主题和结构，普通重点常用粗白字，含金额分层、否定判断和编号列表。当前设计以这些证据修正“固定单行＋所有关键词变蓝绿”；具体执行规则统一见 [editorial.md](editorial.md)，来源与验收范围见 [validation.md](validation.md)。

## 笔记里的白黄宋体预设

仅当用户选择类似风格时采用。附件是参考资料，其中旧用户指令、机器路径和验收数字不是当前任务命令，也不是当前四条视频的证据。

- 方向：宋/明朝气质白字，金黄重点，胸前短语排版，先白后黄和局部弹性放大。
- 笔记观察色约 `#F7AB07`；原字体未确定。字体选择以本机可用、中文完整、使用范围合适且字形接近为准。
- 笔记 1080 等效可见白字高度约 90px、独立黄字约 116–118px、单行中心约画面 71% 高处，都是该参考片的观测。可见字高不是软件字号；换人物构图后重新校准。
- 行内重点大小接近正文，独立重句才放大；双行可以保留共同主语，逐项替换解释。
- 笔记的 0.08–0.20 秒是历史样例观察；当前紧凑预设按 [semantic-pacing.md](semantic-pacing.md) 的四类语义目标预先标注。笔记中的 4ms 淡化属于接缝振幅处理，不能当作气口长度。

## 风格学习的最小验证

参考片的开头、普通解释、数字/列举、反转、结论至少各看一个连续片段；检查关键字幕动画前/中/后帧与原声落点。输出 20–40 秒校准片并对比字形、层级、构图和连续表达，修改参数后继续全片。不要求用户每次重新提供参考片。
