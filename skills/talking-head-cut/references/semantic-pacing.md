# 先标气口，再应用剪辑

本流程用于真人口播。以下数值是紧凑风格的可调整起点，来自当前用户的节奏偏好，不是行业统一标准。不能把一条片的平均值当作每处气口的目标。

## 1. 转写与内容选择：暂不渲染

先完成 [角色和 take 核对](recording-roles.md)，在可用的主角复述中选择内容。ASR 无词区间可能含低声领读，已标出的 excluded_audio 必须在选段阶段排除；不能用压气口代替删领读。

缓存带词级源时间戳、稳定 ID 的 `transcript.source.json`。先校正重拍、否定词、金额和异常时码，再选保留片段，保存 `selection-plan.json`。该计划表达将要保留的源区间，此时尚未切视频。用 `map_words.py` 将词映射到候选时间轴，得到 `words.selected.json`。

只有句级时间戳时，不可均分字数伪造词级时码；先补齐词级对齐。ASR 空档可能含气声、弱起音和尾音，不能当作已听审的纯静音。标点和 ASR 句界只辅助理解，不直接决定停顿等级。

完成条件：保留内容有源时码和稳定词 ID，异常词有状态，候选时间轴连续且尚未冒充媒体执行结果。

## 2. 一次性列出并标注所有候选

运行（脚本路径相对此 Skill）：

```powershell
python scripts/semantic_pacing.py --prepare --words run/words.selected.json --out run
```

输出 `pause-decisions.json`，包含已有接句和保留片段内部的正间隔、前后词 ID、上下文、源时码、原间隔。Agent 连续读完整观点，再填写每行的 `category` 和具体 `reason`；不能把每行机械标成同类。各类默认目标如下：

|category|判断依据|默认总间隔|通常可调整范围|
|---|---|---:|---:|
|within_sentence|句内语法衔接、并列列举、未说完的条件或宾语|20ms|20–30ms|
|expansion|同一观点的解释、补充、因果展开，如“没有难度，而且……”|30ms|30–40ms|
|sentence|一个完整判断结束，再接独立完整句；仍在同一话题|60ms|50–80ms|
|topic|核心论题、章节、论证方向或行动号召切换|120ms|100–160ms|

`target_ms` 可逐处覆盖默认值。语气、悬念、必要呼吸和情绪转折可超出表内范围，但写明原因；自然短于目标时不补静音。这里的目标是“前一个保留词结束 → 后一个保留词开始”的**总间隔**，不是左右两边各留该时长。

对疑似吞字、ASR 零时长、弱起音、长尾音或有意义吸气，先回看该处带上下文的波形/原声；拿不准则 `preserve: true`，保留并登记待审原因。自动保护已有词边缘最多各10ms，只是数值底线，不能代替真实字音检查。零时长或不确定词相邻气口默认保留。

完成条件：每个候选都有类别、目标（显式或类别默认）、具体理由；保留例外有原因。Agent 根据转写完成这些标注，不要求用户逐句填写。

## 3. 计划检查：尚不执行媒体剪切

```powershell
python scripts/semantic_pacing.py --plan run/selection-plan.json --words run/words.selected.json --decisions run/pause-decisions.json --out run
python scripts/map_words.py --transcript run/transcript.source.json --plan run/edit-plan.json --out run/words.final.json
```

脚本要求所有候选都有且只有一条分类/理由，拒绝漏标、过期 revision、未知候选、重叠话语和小于一帧的画面片段。检查保留词 ID、顺序和实际词长一致，没有跨切口的词；报告分类型统计、原/新平均值及中位数、逐处目标与实际值。所有候选和仅正间隔分别统计，口径保持一致。

在 `words.final.json` 基础上默认生成完整基础字幕，只为少量关键句添加重点。句内切音不能成为字幕清屏的依据：字幕分页和媒体切片 ID 独立，按词 ID 更新字幕引用。只有用户要求滚动动效时才准备 `rolling-editorial.json` / `captions.rolling.json`。

完成条件：计划通过候选覆盖和词覆盖检查；气口统计、字幕分组、重点和所有时间戳引用同一 revision。

## 4. 按批准范围内的计划剪音视频、渲染

每个片段记录源区间和成片区间；保持原速，禁止为凑气口拉伸字音。需要30ms而输出25fps时，使用 `sample_audio_cumulative_video`：音频按48kHz采样剪切，成片字幕跟随精确音频时码；画面切点按累计成片时间取最近帧，不能逐段取整后累加。

音频消费 `source_in_s/source_out_s` 或对应的源采样区间；视频消费 `final_in_frame/duration_frames` 和按 `source.fps` 计算的 `source_in_frame/source_out_frame`。源视频帧相位误差上限为半个源帧，画面切换与音频切换也可能相差半帧；逐切口检查嘴型。`final_in_s/out_s` 表示音频时刻，不能假设它始终等于 `final_in_frame/out_frame ÷ source.fps`。最终只在片尾补不足一帧的尾部，不在气口补时长。

对新切口可加不进入保留字音的约3ms淡入/淡出；不得改变计划的总间隔。若渲染器造成音频固定偏移，输出无声画面并复用规范 PCM 混流，再测同步；不能把历史偏移值写死。

先渲染包含四类节奏/重点的短样，再应用同一计划完成用户要求的全片。局部样片必须标明实际覆盖区间，不冒充全片验收。

完成条件：所要求范围的 MP4/SRT/工程可打开，音视频实际执行边界与计划相符。

## 5. 检查和复用

数值检查：词覆盖、采样长度、累计帧边界、字幕/重点起止、字体真实加载、编码音频与 PCM 波形对齐。听审检查：逐切口是否吞字、爆音、喘不过气或丢失话题层次。未听审写 `not_checked`，总体 `review_required`，不把ASR推算的30ms称为声学实测纯静音30ms。

源文件路径/哈希、ASR配置、风格、revision 和每步产物写入工程说明并复用：

|用户后续改动|重做范围|
|---|---|
|只换字体、颜色、动画|复用转写和音视频剪辑；测字宽与加载，重渲染字幕|
|改单处气口或节奏预设|改对应 decisions；重建映射/字幕时码，复用源转写和字幕语义选择|
|改保留内容、重拍选择|重做相关内容选择、气口和字幕引用；不重复识别未变化的源音频|
|更换原片或发现局部ASR错误|按源变化重做；局部复识别保留源偏移和ID映射|

Agent 用脚本导出候选、检查词覆盖和统计，不在对话中反复打印全部词级 JSON；只汇报例外和关键结果。不要为省 token 省略内容选择、气口标注或实际 QC。

完成条件：`qc.json` 逐项记录 pass/fail/not_checked；交付中标明真实覆盖范围与未审项，保留下一次修改可直接复用的输入及计划。
